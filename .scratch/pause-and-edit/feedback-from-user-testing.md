# Feedback from testing with real users

- I want to be able to edit the code in the editor when in paused/step mode - also remove stop & just have pause?
  - Having both stop & pause is confusing - they do the same thing, from a users point-of-view
- I want run-to-here to run the code up to a particular place in the editor
- I think having step line & step instruction is also confusing. If you put one instruction per-line, which is beginner style, then they're the same. Maybe we should just have "step instruction"?
- Easy access to all the examples to load into the editor - or some kind of "this is what this thing can do" demo mode?
  - Maybe some kind of gallery thing, with tags by username, an add to gallery button
- Ability to change the turtle to a different animal. Maybe gamification, collect coins to be able to change character
- Windows screen is 1280x720, pendown takes whole screen, slightly too big
- Linux screen is 1920x1080, pendown windows is 1406x937
