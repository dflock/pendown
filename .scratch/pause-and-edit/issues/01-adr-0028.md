# ADR 0028: pause, edit and replay, no Stop, and Single Step

Status: resolved
Type: task

## What

`docs/adr/0028-pause-edit-and-replay.md`, recording the spec's decisions: one Pause button that finishes the current instruction; the editor editable while paused; Resume and Single Step after a change replaying the changed program, with the same seed, to as many instructions as were shown; why replay rather than swapping procedures in the paused run; the console ending a paused program; Stop's removal; and Single Step replacing Step line and Step instruction (issue 07).

It changes ADR 0006 ("the editor is read-only while a program is running or paused. Stop unlocks it"), ADR 0012's two step buttons, and the places ADRs 0011, 0021 and 0022 speak of Stop: add a line to each pointing at 0028, as earlier ADRs have been amended.

## Done when

The ADR is written, and 0006, 0011, 0012, 0021 and 0022 point at it where they mention Stop, the read-only editor or the step buttons.
