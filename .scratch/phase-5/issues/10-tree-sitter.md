## Comments

### 2026-10-23: done

`tree-sitter-logo/` has `grammar.js`, the parser generated by tree-sitter-cli 0.25.10, the queries, 7 parse tests in `test/corpus/` and 16 highlight assertions in `test/highlight/`, all passing with `npx tree-sitter-cli@0.25.10 test`. It parses words, numbers, quoted words, variables, operators, lists, arrays with `@origin`, parentheses, comments, and `TO ... END` on several lines or one, in any case. TO and END are keywords only where they can be: in a list they're words, since tree-sitter's lexer only looks for tokens the parser can take. A variable or number after the name is an input, not the body. UCBLogo's optional inputs, `[:size 100]`, parse as a list starting the body: allowing them made the title and the body ambiguous.

A procedure's name and inputs are their own node types, `name` and `parameter`, and the built-in commands are matched with `#match?` and everything else with `#not-match?` on the same list, so no two highlight patterns match one node: editors differ about which wins. The list is generated from the kdl by `crates/pendown-logo/tests/tree_sitter.rs`, which checks it's up to date, and that the Zed extension's copy of the queries is the same. Names in a query string's regex need doubled backslashes: `array\\?`.

`zed/` is the extension: `extension.toml` and `languages/logo/` with the config and the queries. Before publishing: a licence (Pendown has none yet), a repository of its own, and the extension's `rev`.
